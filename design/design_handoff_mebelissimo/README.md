# Handoff: Mebelissimo — сайт мебельной фабрики

## Overview
Дизайн сайта мебельной фабрики Mebelissimo (Кишинёв, mebelissimo.md): главная страница с
анимированным входом в каталог, страница магазина, карточка товара и корзина.
Язык интерфейса — русский с переключением на румынский (RU/RO).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие
внешний вид и поведение, а не продакшн-код для копирования. Задача — **воссоздать эти
макеты в целевой кодовой базе** (React / Next / Vue и т.д.), используя её принятые паттерны,
роутинг и библиотеки. Если кодовой базы ещё нет — выбрать подходящий фреймворк и
реализовать макеты в нём.

Каждый файл `*.dc.html` открывается в браузере напрямую: разметка, стили (инлайн) и логика
(класс `Component`) лежат в одном файле. Логика — обычный JS-класс уровня React-компонента:
`state`, `componentDidMount`, обработчики; метод `renderVals()` возвращает значения, которые
подставляются в разметку. Читать его следует как описание поведения, а не как готовый код.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы и анимации. UI следует
воспроизводить попиксельно, подставив собственные фотографии товаров.

## Screens / Views

### 1. Главная — `Mebelissimo Home.dc.html`
**Назначение:** первое, что видит посетитель; ведёт в магазин.

**Экран 1 (hero, 100vh):**
- Шапка фиксированная, grid из 3 колонок (`1fr auto 1fr`), паддинг `26px clamp(20px,4vw,56px)`:
  логотип слева, меню по центру, переключатель языка + корзина справа.
- Логотип: контейнер `clamp(180px,18vw,252px) × clamp(34px,3.6vw,48px)`; внутри два слоя,
  оба `position:absolute; left:50%; top:50%`, сдвиг `translateX(-40px)`. Наверху страницы виден
  знак-диван (`mebelissimo-mark.svg`), при `scrollY > 48` он уходит вверх на 20px и исчезает
  (opacity .5s), а снизу с задержкой .3s поднимается надпись (`mebelissimo-word.svg`).
  Оба SVG — маски (`mask-image` + `background: currentColor`), поэтому цвет наследуется:
  `#2b2621`, при наведении `#8a6a4b`, переход .45s.
- Меню: «Магазин», «Дизайнерам», «Контакты». `font-size: clamp(12px,1.15vw,14px)`,
  `letter-spacing .11em`, uppercase, цвет `#4a443d`; hover — цвет `#8a6a4b` и трекинг `.14em`.
- Переключатель RU/RO: без рамки; тёмная «капля» (`#2b2621`, радиус 999px) скользит под
  активной подписью, кривая `cubic-bezier(.34,1.42,.42,1)`, .55s, с коротким сжатием
  `scale(1.16,.82)` на 200ms. Ширины пунктов шапки зафиксированы по большему из RU/RO,
  чтобы кнопки не прыгали при переводе.
- Корзина: текст + счётчик — круг `#8a6a4b`, текст `#fdfbf7`, 10.5px.
- Контент героя: надзаголовок «Мебель по индивидуальным проектам · Chișinău»,
  заголовок «Ваши идеи — наша реализация» (Playfair Display, `clamp(44px,6.4vw,104px)`),
  абзац, кнопка «Перейти в магазин» (тёмная плашка `#2b2621`, hover `#8a6a4b`) и
  текстовая ссылка «Дизайнеры как партнёры». Появление — `mb-rise` с шагом задержки ~.12s.
- Строка статистики: «43 кровати · 23 детские · 8 диванов · выбор обивки», без подложки.
- Полоса из 5 плиток-категорий (Кровати, Кровати детские, Диваны, Шкафы-купе, Кухни):
  прямые углы, вплотную друг к другу, высота
  `Math.max(96, Math.min(innerWidth/5, Math.max(hero.clientHeight - rowTop, innerHeight*0.56) + 20))`.
  **Этот размер утверждён заказчиком — не менять.**
  При прокрутке плитки поднимаются с разной силой (крайние сильнее, центральная слабее).
  Hover: плавное затемнение (отдельный слой, opacity 0→1, .77s) и увеличение подписи
  до `scale(1.07)` с трекингом .12em (1.1s). Ни сдвига, ни следования за курсором.

**Экран 2 (каталог поверх героя):** при прокрутке главная остаётся неподвижной, а секция
кроватей наезжает сверху. Верхняя кромка секции — градиент прозрачности высотой

## Interactions & Behavior
- Переключение языка: все переводимые узлы помечены `data-ro`; исходный русский текст
  сохраняется в `data-ru` при первом переключении. Строки, приходящие из логики
  (фильтры, сортировка, названия товаров, суммы), переводятся в `renderVals()`.
  В продакшне это нужно заменить на обычную i18n-библиотеку.
- Все внешние переходы отключены намеренно: кнопки ведут только между страницами макета.
- Анимации входа: `@keyframes mb-rise` (opacity 0→1, translateY 24px→0) и `mb-fade`.
- Прокрутка обрабатывается через `requestAnimationFrame`, слушатели `{ passive: true }`.
- Наведение на карточки — только показ кнопки, без подъёма и масштабирования самой карточки.

## State Management
Главная: позиция прокрутки → прогресс наезда панели; флаги показа карточек и отзывов.
Магазин: `{ filter, sort, shown }`. Товар: `{ qty, size, fabric, tab, added }`.
Корзина: `{ lines: [{ name, price, qty, size, fabric, term }], promo }`.
Данных с сервера нет — каталог зашит массивом; в реальном проекте это API каталога.

## Assets
- `mebelissimo-mark.svg` — знак-диван, вырезан из логотипа заказчика; фон и просветы
  букв сделаны вырезами через `<mask>`, цвет берётся из `currentColor`.

- Фотографии не входят в пакет: в макете стоят пустые слоты.
